Endpoint contract

Read the current section with GET or update supplied fields with PATCH.

MethodsGET, PATCH
AuthenticationBearer access token
Endpoint{{ documentation.endpoint }}

Authorization

Send Authorization: Bearer <access_token>. Managers and system administrators can access every prospect. A sales intern, inside-sales user, or LinkedIn-outreach user must own the exact prospect. Unassigned or another user's prospect returns HTTP 403.

PATCH accepts a JSON object. Send only fields that should change; omitted fields retain their values. Every successful PATCH creates a prospect update audit containing the authenticated user, previous values, changed values, and timestamp.

Responses

All API responses use JSON and Cache-Control: no-store.

StatusMeaning
200GET succeeded or PATCH was validated, saved, and audited.
400Malformed JSON, unsupported field, invalid type/value, or a workflow validation rule failed.
401The bearer token is missing, invalid, revoked, or belongs to an inactive user.
403The token user does not own this prospect and is not a manager or system administrator.
404The numeric prospect ID does not exist.
405The endpoint received a method other than GET or PATCH.
